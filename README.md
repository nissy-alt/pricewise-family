# PriceWise

เว็บแอปภาษาไทยสำหรับเทียบราคาสินค้า 2–5 รายการบนมือถือ คิดราคาต่อ 100 มล., 100 กรัม หรือ 1 ชิ้น รองรับหน่วย มล./ลิตร, กรัม/กก., จำนวนแพ็ก, ส่วนลดเปอร์เซ็นต์และคูปอง, ประวัติใน localStorage และแชร์ข้อความผ่าน LINE

**เปิดใช้งาน:** https://pricewise-family.pages.dev/

บน iPhone ให้เปิดลิงก์ใน Safari แล้วใช้เมนูแชร์ > เพิ่มไปยังหน้าจอโฮม เพื่อเปิดแบบแอป

## ใช้งานและเผยแพร่

เป็นเว็บไซต์แบบ static ไม่มี dependency, API, ฐานข้อมูล หรือขั้นตอน build เปิด `index.html` ผ่านเว็บเซิร์ฟเวอร์ในเครื่อง หรือเผยแพร่โฟลเดอร์นี้ด้วย Cloudflare Pages โดยตั้ง output directory เป็น `.` และไม่ต้องใส่ build command

ข้อมูลประวัติและแบบร่างอยู่ในเบราว์เซอร์ของแต่ละเครื่อง ไม่ซิงก์ข้ามเครื่อง การแชร์ LINE ส่งเฉพาะข้อความสรุปที่ผู้ใช้กดแชร์

## ตัวอย่างตรวจสอบ

- 400 มล. ราคา ฿159 = ฿39.75 ต่อ 100 มล.
- 500 มล. ราคา ฿184 = ฿36.80 ต่อ 100 มล.
- 500 มล. ถูกกว่าต่อหน่วย `(39.75 - 36.80) / 39.75 × 100` = **7.42%**
