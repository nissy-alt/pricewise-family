PRICEWISE × LINE OA เจ๊หลี

ความเป็นส่วนตัวของคุณ

ผู้ให้บริการ PriceWise และบอตใน LINE คือบัญชีทางการ “เจ๊หลี” (@271vuavh) หน้านี้อธิบายการใช้ข้อมูลเมื่อคุณเปิดเว็บหรือส่งข้อความหาบัญชีนี้

เมื่อใช้เว็บไซต์ PriceWise

ข้อมูลสินค้า ราคา ส่วนลด และประวัติที่คุณบันทึกเก็บไว้ในพื้นที่เก็บข้อมูลของเบราว์เซอร์บนอุปกรณ์ของคุณ (localStorage) แอปไม่ได้สร้างบัญชีผู้ใช้หรือเก็บประวัตินี้ในฐานข้อมูลส่วนกลาง คุณลบประวัติได้ในแอป หรือล้างข้อมูลเว็บไซต์ในเบราว์เซอร์

เมื่อใช้บอตใน LINE

หากเปิดใช้งานบอต LINE จะส่งข้อความที่คุณพิมพ์และข้อมูลประกอบเหตุการณ์ไปยังระบบของ PriceWise ผ่าน Cloudflare เพื่อคำนวณและตอบกลับ บอตใช้ข้อความเพื่อการตอบครั้งนั้น และไม่ได้บันทึกข้อความหรือ LINE user ID ลงฐานข้อมูลของ PriceWise ระบบของ LINE และ Cloudflare อาจประมวลผลข้อมูลตามนโยบายและบันทึกระบบของตน

การแชร์และระยะเวลาเก็บ

ปุ่มแชร์ LINE ให้คุณเลือกผู้รับเองก่อนส่ง PriceWise ไม่ส่งประวัติการเปรียบเทียบให้ผู้อื่นโดยอัตโนมัติ ข้อมูลใน localStorage อยู่บนอุปกรณ์จนกว่าคุณจะลบหรือเบราว์เซอร์ล้างข้อมูล ข้อความที่ส่งผ่าน LINE อยู่ภายใต้นโยบายการเก็บข้อมูลของ LINE
